## Overview

Nimt.ai is an AI search analytics platform that helps brands understand and optimize their visibility across large language models like ChatGPT, Perplexity, and Gemini.

As the frontend lead, I drove the development of the entire user-facing application — from complex data visualizations to the marketing site.

## My Role

- **Frontend Architecture** — Restructured the existing codebase upon joining, improving maintainability and setting a stronger foundation for rapid feature development.
- **Data Visualization** — Designed and built interfaces that make complex AI-driven metrics — brand sentiment scores, source tracking, cross-model visibility rankings — intuitive and actionable.
- **Rebrand & Marketing** — Spearheaded the full visual rebrand and rebuilt the marketing site from scratch using Framer.
- **UX Focus** — Championed a user-first approach, ensuring that dense analytics data was always presented clearly.

## Technical Highlights

The platform ingests data from multiple LLM providers and presents it through interactive dashboards. Key technical challenges included real-time data aggregation, responsive chart rendering, and building a design system that scaled across the product and marketing surfaces.

The stack leverages Next.js with TypeScript for type safety, Tailwind CSS for rapid UI iteration, and tight Figma-to-code workflows for pixel-perfect implementation.
