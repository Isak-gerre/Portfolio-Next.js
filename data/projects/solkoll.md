## Overview

Solkoll is a CMS and document creation platform that enables users to build, manage, and export professional documents with an intuitive drag-and-drop interface.

As the sole developer, I owned every aspect of the application — from architecture decisions to pixel-level UI polish.

## My Role

- **Sole Developer** — Designed, built, and maintained the entire application independently.
- **Interactive Documents** — Built a rich document editor with interactive elements, custom layouts, and real-time preview.
- **Layout Builder** — Created a flexible string layout builder that lets users compose complex document structures visually.
- **PDF Generation** — Implemented server-side PDF generation that faithfully reproduces the on-screen document layout.

## Technical Highlights

The most interesting technical challenge was the layout builder — allowing non-technical users to compose sophisticated document layouts through a visual interface, then rendering those layouts consistently across screen and PDF output.

The application runs on Next.js with TypeScript, uses Material UI for the component library, and is deployed on AWS using the SST framework. Intercom integration provides in-app customer support.
