## Overview

Bingy is a web application that lets users browse, discover, and curate personalized movie lists. Built as a school project, it served as a deep dive into full-stack web development fundamentals.

## My Role

- **Solo Developer** — Designed and built the entire application from concept to deployment.
- **Database Design** — Modeled the relational data structure for users, movies, and lists in MySQL.
- **Frontend & Backend** — Built the UI with vanilla HTML, CSS, and JavaScript, with PHP handling server-side logic and database queries.

## Technical Highlights

This project was an exercise in building a complete web application without frameworks — understanding the fundamentals of HTTP requests, server-side rendering with PHP, SQL query optimization, and responsive CSS layouts. The movie data was sourced and structured to support filtering, search, and user-generated lists.
