## Overview

Savery.ai is a platform for autonomous software development. It orchestrates a network of AI agents that collaborate to deliver high-quality, end-to-end developed software — from requirements gathering through to deployment.

## My Role

- **Full Stack Development** — Built features across the entire stack, from the React frontend to backend services running on GCP.
- **Agent Interface Design** — Designed the UI for monitoring and interacting with the AI agent network, making complex multi-agent workflows transparent and controllable.
- **Infrastructure** — Worked with Docker and GCP to build reliable deployment pipelines for the platform.

## Technical Highlights

The core challenge was building an interface that could represent the complexity of multiple AI agents working in parallel — showing their progress, decisions, and outputs in a way that felt coherent rather than overwhelming.

Built with Next.js, TypeScript, and Shadcn UI components, the frontend communicates with a distributed backend running containerized services on Google Cloud Platform.
